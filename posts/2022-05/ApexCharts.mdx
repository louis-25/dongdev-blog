# ApexCharts.js란?

ApexCharts.js는 차트를 그려주는 자바스크립트 라이브러리다

이것을 사용하여 리액트에서 차트를 그려보자

# 사용법

우선은 아래의 코드로 apexcharts를 설치해주자

```typescript
npm install --save react-apexcharts apexcharts
```

아래와같이 간단하게 사용해볼 수 있다

```typescript
import React, { FunctionComponent } from "react";
import ApexCharts from "react-apexcharts";

interface ChartsProps {
  coinId: string;
}

const Chart: FunctionComponent<ChartsProps> = ({ coinId }) => {
  return (
    <div>
      <ApexCharts
        type="line"
        series={[
          {
            name: "hello",
            data: [1, 2, 3, 4, 5, 6],
          },
          {
            name: "sales",
            data: [15, 16, 17, 15, 10, 2],
          },
        ]}
        options={{
          chart: {
            height: 500,
            width: 500,
          },
        }}
      ></ApexCharts>
    </div>
  );
};

export default Chart;
```
