# react-beautiful-dnd란?

react-beautiful-dnd는 react에서 컴포넌트를 쉽게 드래그 할 수 있게 해주는 라이브러리다

# 구조

우선 드래그를 하고싶은 영역에 DragDropContext로 감싸준 후

Droppable역역을 지정해주고 실제 드래그가 일어날 컴포넌트들을 Draggable로 감싸주면

드래그 기능이 정상적으로 작동한다

# 사용법

1. react-beautiful-dnd 를 설치한다

```typescript
yarn add -D react-beautiful-dnd
```

2. DragDropContext로 감싸준다

3. Droppable 영역을 만든다

4. 드래그할 컴포넌트를 Draggable태그로 감싸준다

5. Draggable에 각종 태그 추가

   1. key, draggableId, index값 설정
   2. ref, dragHandleProps, draggableProps값 설정

## dragHandleProps와 draggableProps

draggableProps - 기본적으로 요소 전체가 드래그됨

dragHandleProps - 특정 영역을 통해서만 드래그를 가능하도록 하고 싶을 때 사용한다.

## DropResult

DropResult는 드래그된 요소의 정보를 가져오는 함수이다

- draggableId - 드래그된 요소의 ID
- destination - 드래그가 끝날때 요소의 위치
- source - 드래그가 시작될때 요소의 위치

```typescript
const onDragEnd = ({ draggableId, destination, source }: DropResult) => {
  if (!destination) return;
  setToDos((oldToDos) => {
    const toDosCopy = [...oldToDos];
    // 1) Delete item on source.index
    console.log("Delete item on", source.index);
    console.log(toDosCopy);
    toDosCopy.splice(source.index, 1);
    console.log("Deleted item");
    console.log(toDosCopy);
    // 2) Put back the item on the destination.index
    console.log("Put back", draggableId, "on ", destination.index);
    toDosCopy.splice(destination?.index, 0, draggableId);
    console.log(toDosCopy);
    return toDosCopy;
  });
};
```
