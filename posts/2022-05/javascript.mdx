# Javasciprt 함수 즉시 실행하는법

자바스크립트를 쓰다보면

간단한 함수의 경우 생성 후 바로 호출하여

코드를 줄이고 싶을때가 있다

그럴때 아래의 코드와같이 사용해보자

```typescript
(() => console.log("함수가 바로 실행된다"))();
```

이를 응용하여

리액트에서 아래와 같이

API데이터를 비동기 호출할때 사용하기도 한다

```typescript
useEffect(() => {
  // 즉시 실행되는 코드
  (async () => {
    const response = await fetch("https://api.coinpaprika.com/v1/coins");
    const json = await response.json();
  })();
}, []);
```
