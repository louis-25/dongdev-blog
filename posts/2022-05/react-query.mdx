# React Query란?

React-Query는 <code>redux-saga</code>나 <code>redux-thunk</code>와 같은 서버사이드 상태 관리 라이브러리로

[tanstack](https://tanstack.com/)에서 만들었으며 React앱에서 비동기 로직을 쉽게 다루게 해준다

# 사용법

react-query를 사용하려면 제일먼저

최상위 컴포넌트에 프로바이더로 감싸줘야한다

```typescript
import React from "react";
import ReactDOM from "react-dom/client";
import { QueryClient, QueryClientProvider } from "react-query";
import App from "./App";

const root = ReactDOM.createRoot(
  document.getElementById("root") as HTMLElement
);

const queryClient = new QueryClient();

root.render(
  <React.StrictMode>
    <QueryClientProvider client={queryClient}>
      <App />
    </QueryClientProvider>
  </React.StrictMode>
);
```

# useQuery

React-Query에서 제공하는 useQuery훅은

한번 데이터를 받아오면 우선 캐시에 저장해놓는다

이후 캐시에 데이터가 존재하면 서버에 데이터를

다시 요청하지않고 저장된 데이터를 사용하므로

필요없는 데이터 요청을 줄이고 속도가 개선되는 효과를 볼 수 있다

useQuery의 기본 구조는 아래와 같다

```typescript
const { isLoading, data, error } = useQuery(queryKey, queryFn, options);
```

- isLoading: 캐시가 없는 상태에서 데이터를 요청 중인 상태
- data: 서버 요청에 대한 데이터
- error: 서버 요청 실패

* queryKey: query의 고유 식별자로 중복되지 않을만한 값으로 지정해주자( 중복되면 안됨! )
* queryFn: 서버에 데이터를 요청하는 함수
* options: query에 대한 옵션을 지정

아래는 useQuery를 사용하는 간단한 예시이다

```typescript
import { fetchCoins } from "../api";

interface ICoin {
  id: string;
  name: string;
  symbol: string;
  rank: number;
  is_new: boolean;
  is_active: boolean;
  type: string;
}

const { isLoading, data } = useQuery<ICoin[]>("allCoins", fetchCoins);
```

```typescript
/* api.ts */
const BASE_URL = `https://api.coinpaprika.com/v1`;

export function fetchCoins() {
  return fetch(`${BASE_URL}/coins`).then((response) => response.json());
}
```

## queryKey가 중복될 경우

useQuery의 queryKey인자값은 중복되면 안된다

만약 queryKey가 중복된다면 다음과 같이 해결하자

```typescript
// isLoading과 data의 경우도 useQuery를 2개이상 호출하면 중복되므로
// 아래와같이 커스텀하여 호출하도록 하자
const { isLoading: infoLoading, data: infoData } = useQuery<InfoData>(
  ["info", coinId], // queryKey는 info에 coinId값으로 저장된다
  () => fetchCoinInfo(coinId)
);
const { isLoading: tickersLoading, data: tickersData } = useQuery<PriceData>(
  ["tickers", coinId],
  () => fetchCoinTickers(coinId),
  {
    refetchInterval: 5000, //5초에 한번씩 데이터가 바뀌었는지 서버에 요청하여 확인
  }
);
```

# React Query Devtools

React Query의 모든 내부 작동을 시각화하는 데 도움이 되며

문제가 발생하면 디버깅 시간을 절약할 수 있다

사용법은 아래와 같다

```typescript
import React, { useState } from "react";
import Router from "./Router";
import { ReactQueryDevtools } from "react-query/devtools";

function App() {
  return (
    <>
      <Router></Router>
      <ReactQueryDevtools initialIsOpen={true} />
    </>
  );
}

export default App;
```
