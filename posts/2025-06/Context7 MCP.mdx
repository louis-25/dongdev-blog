사내 **Lumos** 서비스에는 이메일 공지 기능이 포함되어 있습니다.  
이메일 내용을 작성하는 텍스트 에디터를 개선하기 위해, 최신 문서를 기반으로 코드를 자동 수정해주는 **Context7 MCP**를 활용해 보았습니다.

---

# 소개

## 왜 Context7 MCP를 도입했는가?

- **목적**: Lumos 이메일 공지 기능의 텍스트 에디터 개선
- **이유**: 기존에는 최신 문법 반영이 어려워 코드 오류가 잦았음 → MCP로 자동 최신 문서 참조

---

# 진행 과정

## 1. Context7 MCP 설치

- [smithery.ai Context7 MCP 서버](https://smithery.ai/server/@upstash/context7-mcp) 접속
- **Cursor 버튼 클릭** 후 IDE에 설치
- `Cursor Settings > Tools & Integrations > MCP Tools` 메뉴에서 Context7 활성화 확인
- (_로컬에서 직접 MCP 서버 실행도 가능 → [Github - upstash/context7](https://github.com/upstash/context7) 참고_)

## 2. Cursor에서 질문할 때 활용

- 질문 시 반드시 **“context7 MCP를 참고해서 답변해줘”** 문구 포함
- Cursor가 `resolve-library-id`, `get-library-docs` 등의 MCP 함수를 호출해 최신 문서를 불러옴

# 결과 및 사용팁

## 개선 효과

- **Before**: 직접 문서를 찾아야 해서 오류 잦음
- **After**: MCP가 자동으로 최신 문서 반영 → 코드 정확성과 생산성 향상

## 배운 점 & 팁

1. 질문할 때 반드시 **context7 MCP 참고**라고 명시할 것
2. MCP 함수 호출 로그(`Called resolve-library-id`, `Called get-library-docs`) 확인으로 동작 여부 점검
3. 최신 문서 반영이 필요한 프로젝트라면 적극 활용 권장

## 시행착오

- 설치 후 `Cursor Settings`에서 활성화를 놓쳐 MCP가 동작하지 않은 적이 있었음
- MCP를 언급하지 않으면 단순 GPT 답변만 반환됨

## 앞으로의 계획

- Lumos의 **공지 자동화**, **이메일 템플릿** 기능에도 적용 확대
- 프롬프트 전략:
  - “최신 문서 기반으로 코드 수정”
  - “context7 MCP 활용”
  - “예제 코드 포함”
