## GitLab Runner란?

GitLab Runner는 GitLab의 CI/CD 파이프라인을 처리하는 도구로, 작업을 실행할 환경(예: 로컬 서버, 가상 머신, 클라우드 등)에서 직접 빌드, 테스트, 배포 등의 작업을 수행합니다. 여러 Runner를 동시에 실행할 수 있으며, 각 Runner는 파이프라인에서 정의된 작업을 실행할 수 있도록 설정됩니다.

---

## GitLab Runner 설치 및 설정 방법

### 1. GitLab Runner 설치

GitLab Runner는 다양한 환경에서 설치할 수 있습니다. 여기서는 Ubuntu에서 설치하는 방법을 예시로 보여드리겠습니다.

```bash
# GitLab Runner 패키지 저장소 추가
sudo apt-get install -y curl
curl -L --output /tmp/install.sh https://packages.gitlab.com/install/repositories/runner/gitlab-runner/script.deb.sh
sudo bash /tmp/install.sh

# GitLab Runner 설치
sudo apt-get install gitlab-runner
```

### 2. GitLab Runner 등록

GitLab Runner를 설치한 후에는 GitLab 인스턴스에 Runner를 등록해야 합니다. 이 등록 과정은 GitLab에서 제공하는 등록 토큰을 사용하여 Runner를 연결합니다. 아래 명령어를 통해 Runner를 등록합니다.

- **GitLab 서버 URL**: GitLab 서버의 URL을 입력합니다. 예를 들어, https://gitlab.com/ 또는 사내 GitLab 서버의 URL을 입력합니다.

- **등록 토큰**: GitLab 프로젝트나 그룹의 CI/CD 설정에서 확인할 수 있는 등록 토큰을 입력합니다.

- **Runner 설명**: 이 Runner의 이름을 지정할 수 있습니다. 예: my-runner.

- **Runner 실행 환경**: Runner가 사용할 환경을 선택합니다. 예를 들어, Docker를 사용할 경우 docker를 선택할 수 있습니다.

- **태그**: 작업을 특정 Runner에서만 실행하게 하려면 태그를 사용할 수 있습니다.

### 3. GitLab Runner 실행

GitLab Runner를 설치하고 등록한 후에는 서비스를 실행할 수 있습니다. gitlab-runner는 자동으로 시스템 서비스를 관리할 수 있습니다.

```bash
sudo gitlab-runner start
```

### 4. Docker Executor 사용 (선택 사항)

GitLab Runner는 기본적으로 여러 Executor를 지원합니다. 예를 들어, Docker를 사용하여 독립된 환경에서 파이프라인을 실행할 수 있습니다. Docker Executor를 사용하려면 Docker가 설치된 상태여야 하며, Runner를 설정할 때 Docker를 Executor로 선택할 수 있습니다.

예를 들어, Docker Executor를 사용할 때는 <code>.gitlab-ci.yml</code> 파일에 Docker 이미지를 설정하여 작업을 실행할 수 있습니다:

```yaml
build_job:
  stage: build
  image: node:14 # Docker 이미지 사용
  script:
    - npm install
    - npm run build
```

### 5. GitLab Runner 관리

GitLab Runner를 관리하는 명령어들도 있습니다. 예를 들어:

- **등록된 Runner 확인**: <code>sudo gitlab-runner list</code>

- **Runner 중지**: <code>sudo gitlab-runner stop</code>

- **Runner 삭제**: <code>sudo gitlab-runner unregister --name `<runner_name>`</code>
