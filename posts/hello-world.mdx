# Welcome to my blog!

This is my first blog post using **MDX** with Next.js. Here's a code example:

```typescript showLineNumbers {3-4}

  // Say hello to the user

}
```

And here's another example with a different theme:

```python
def fibonacci(n):
    if n <= 1:
        return n
    else:
        return fibonacci(n-1) + fibonacci(n-2)

# Print first 10 Fibonacci numbers
for i in range(10):
    print(fibonacci(i))
```

You can now:

1. Switch between different themes
2. Copy code blocks
3. See line numbers
4. Highlight specific lines

```typescript
// 타입스크립트 코드 예제
interface User {
  id: number;
  name: string;
  email: string;
}

function greet(user: User) {
  console.log(`Hello, ${user.name}!`);
}

const user: User = {
  id: 1,
  name: "John Doe",
  email: "john@example.com",
};

greet(user);
```
